# DevicePulse — Product Requirements Document

## Overview
**DevicePulse** by Verolane Digital Solutions is a professional device health and optimization app for iOS and Android. It combines a polished visual dashboard with actionable cleanup tools and AI-powered recommendations.

## Brand
- Logo: stylized "V" with circuit-line details (Skia on native, gradient tile fallback on web)
- Palette: deep navy-teal (#050F14 → #0B1B24) to fresh green (#10B981 → #059669)
- Voice: high-trust, calm, tech-forward, reassuring

## Key Features
1. **Splash + Onboarding** — animated V logo, 3-slide feature tour (health, smart scan, privacy)
2. **Home Dashboard** — animated Skia health ring, quick stat grid (Storage, Memory, Battery, Security), Smart Scan CTA
3. **Smart Scan** — animated multi-step scan flow with reclaimable-space summary
4. **Review & Clean** — category-level selection (Junk / Duplicates / Large files / Cache) with reassuring confirmation modal before any action
5. **Before/After Results** — celebratory success screen with side-by-side health-ring comparison
6. **Duplicate Photos** — grouped thumbnails, keep-best logic, MB saved counter
7. **Large File Finder** — sortable file list with type icons
8. **Insights (Storage / Battery / Security)** — segmented chip navigation
   - Storage: total + breakdown by category (stacked bar + legend)
   - Battery: level, health %, cycles, temperature, top drain apps
   - Security: safe/at-risk hero + threat list
9. **AI Recommendations** — 4 personalized tips generated by Claude Sonnet 5 based on live device stats (with graceful fallback)
10. **Pro Paywall** — hero image, feature list, monthly/yearly plans, 7-day trial CTA
11. **Settings** — preferences toggles, support & about links, Pro upsell banner

## Tech Stack
- **Frontend:** Expo SDK 54, expo-router, React Native Reanimated, @shopify/react-native-skia (native only), expo-blur, expo-linear-gradient, expo-image, expo-haptics
- **Backend:** FastAPI + Motor (MongoDB) + emergentintegrations (Claude Sonnet 5)
- **Storage:** MongoDB (`scans`, `cleanups` collections)

## API Endpoints
| Method | Path | Purpose |
|---|---|---|
| GET | `/api/device/health` | Overall device health snapshot |
| GET | `/api/device/storage` | Storage totals + breakdown |
| GET | `/api/device/duplicates` | Duplicate photo groups |
| GET | `/api/device/large-files` | Large files list |
| GET | `/api/device/battery` | Battery insights + top drain apps |
| GET | `/api/device/security` | Security status + threats |
| POST | `/api/device/scan` | Run smart scan (returns reclaimable breakdown) |
| POST | `/api/device/clean` | Apply cleanup, returns health before/after |
| POST | `/api/ai/recommendations` | AI-generated optimization tips |

## Platform Behavior
- **Android:** copy references deeper cleanup where OS permits
- **iOS:** copy emphasizes App-Store-compliant, privacy-safe tools

## Simulated Data
All device stats are simulated (server-side seed) — real deep-cleanup requires native modules. Positioned as a polished preview/demo.
